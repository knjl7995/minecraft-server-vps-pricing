## 先做减法：这4个套餐开MC用不上

VM-8、VM-12、VM-16这三个16GB以上的档位，跑《我的世界》是浪费。MC服务端的主要运算是单线程的，多出来的核心对TPS帮助有限，钱花在核数上不如花在主频上。真正需要这种配置的是同时开好几个服务端实例、或者一台机器上跑群组服加多个子服。

VM-0.5和VM-0.75也别碰。512MB和1GB内存连Java虚拟机加系统本身都紧张，开服第一步就会被OOM打断。

剩下的档位里，VM-1（1核2GB，$5.99）和VM-1.5（2核2GB，$6.95）价格接近，区别只在核心数。纯净原版加两三个朋友，这两个都能跑；VM-1.5只贵$0.96，多一个核心处理区块加载和异步任务，更从容一些。VM-3（4核4GB，$14.99）是个尴尬档：核多但内存和VM-2一样，模组服吃的是内存不是核，加$9买VM-2的四核版意义不大，不如直接跳到VM-4。

## 我的世界吃的是单核，不是核数

这条几乎是所有开服教程的共识：MC服务端主要单线程运行，也会用到多核，但主要运算集中在一个核心上，单核性能越强，TPS越稳定。1.18之后的新版本把单核需求拉得更高，拿一颗2.9GHz的老至强开模组服，TPS掉到15都不算意外。

Evoxt的定价页把"单核最高6.0GHz"当成核心卖点写在最上面，这个方向对MC是对的。需要说清楚的是，官网写的是"Up to 6.0 GHz"，属于上限描述，没有公布具体CPU型号，也没有承诺每个套餐都跑满这个频率。真实单核表现要看具体宿主机，这一点在别处查不到，只能自己压测或问客服要CPU型号。

一篇2024年的1.21开服教程给的建议更保守：服务器配置"4核8G以上，最低不要低于4核8G"，CPU要选14900K、13900K、5900X这类高主频型号。这是博主针对1.21 Java版加模组的个人口径，不是官方要求，但可以参考它的方向——高版本确实吃单核和内存。

## 带宽比核数更容易被忽略

华纳云那份文档里有一条常被跳过但很实用的提醒：如果服务器只给3Mbps上行，6~8人同时在线就可能卡顿，最好选10Mbps以上。MC的带宽消耗不算大，但区块加载、玩家移动同步、插件通信叠在一起，小口子会先撑不住。

Evoxt的定价页只标月流量（250GB到5TB），**没有写端口带宽是多少Mbps**。这不是小问题：月流量够不代表瞬时带宽够，1TB流量听着很多，如果端口只有几Mbps，人多的时候照样卡。下单前值得单独问一句端口速率，或者先买一个月实测。

磁盘同理。官方页面标注了容量，没有明确标注介质类型。MC的区块读写对IO敏感，机械硬盘会明显拖慢加载速度，这一点在选任何服务商时都成立。

## Evoxt是裸VPS，不是带面板的游戏服

这是决定你要不要选它的关键。

国内一些厂商卖的是"游戏云"：自带MCSM可视化面板，点几下鼠标就能选Paper或Forge、一键启动、自动备份，代价是端口和端口映射受服务商限制，NAT模式下还要手动转发25565。Evoxt卖的是标准VPS，没有任何游戏面板，给你一台干净的Linux或Windows机器，剩下全部自己来。

自己来意味着这些步骤：

1. 选系统镜像。Ubuntu 24.04 LTS或CentOS 8以上，**CentOS 7装新版MCSManager会直接提示系统版本过低**，开服第一天就卡住。
2. 装JDK。1.21需要JDK 21。
3. 上传服务端jar。原版、Paper、Fabric直接`java -jar`跑；Forge 1.16.5以上要先执行一次`-installServer`，再用生成的`run.sh`启动，并编辑`user_jvm_args.txt`改内存。
4. 首次启动会提示`You need to agree to the EULA`，去`eula.txt`把false改成true。
5. 开放25565端口。装了MCSManager的话还要开放面板23333和守护进程24444。用非root用户跑服务时，`world`文件夹权限要`chown`过去，否则存档写不进去。
6. 想加模组，原版`server.jar`不行，得换Fabric或Forge，而且**服务端模组本地和服务器必须完全一致**，Fabric API是硬前置。

能走完这套流程，Evoxt的自由度和价格都划算；走不完，多花的钱会变成熬夜。想要面板的话，MCSManager本身是开源免费的，可以自己装在Evoxt的机器上，官方提供一键脚本，只是安装和排错要自己负责。
